## R1.08 — Les fonctions dans l'entreprise

### Direction générale

- **Mintzberg** : relationnel (contacts), informationnel (collecte/diffusion d'informations), décisionnel (arbitrages et décisions face aux imprévus).
- **Porter** : chaîne de valeur = activités qui transforment des inputs en outputs. **Marge = valeur − coûts**.
- Activités principales : **logistique interne, production, logistique externe, commercialisation/vente, services**.
- Activités de soutien : **infrastructure, RH, développement technologique, approvisionnement**.

### Fonctions principales

**Logistique** : optimiser les flux. Amont = fournisseurs ; interne = à l'intérieur ; aval = clients. **WMS** = entrepôt.

**Production** : 4 objectifs = **rentable, qualité, flexible, réactive**. Modes : **unitaire, petite série, grande série**. **Push** = production anticipée/stock ; **Pull** = commande client qui déclenche la production. **Économie d'échelle** = coût unitaire qui diminue quand les quantités produites augmentent. **GPAO** = production ; **GMAO** = maintenance.

**Marketing** : stratégique = **segmentation → ciblage → positionnement** ; opérationnel = **produit, prix, communication, distribution**. **CRM** = relation client.

### Fonctions supports

**Comptabilité/finance** : information comptable, trésorerie, financement, placement, investisseurs.

**RH** : besoins en personnes/compétences, carrières, relations sociales. Rémunération = directe / indirecte / immatérielle. **Dédit-formation** = remboursement possible des frais de formation en cas de départ avant le délai prévu. **Principe de Peter** = promotion selon les compétences nécessaires au nouveau poste. **ATS** = recrutement ; **LMS** = formation.

**R&D** : recherche = nouvelles connaissances ; développement = application concrète. **Brevet** = monopole temporaire d'exploitation, avec possibilité de licence ou de vente.

**Approvisionnement** : matières premières/composants au meilleur rapport qualité/prix. Court terme : prix important ; long terme : fiabilité importante.

### GSI

**SI** = ressources humaines, matérielles, logicielles et données permettant de **collecter, stocker, traiter et diffuser** l'information.

Missions : infrastructure, applications métier, intégration, cybersécurité/RGPD, accompagnement des utilisateurs, transformation numérique.

**Intégration d'applications** = faire communiquer les logiciels pour éviter ressaisies et erreurs.

La GSI est généralement une activité de **soutien**, mais peut être **principale** lorsque le SI est directement le produit ou le canal du service vendu.

### BUT Informatique

- **Réalisation d'applications : conception, développement, validation** → développement logiciel.
- **Intégration d'applications et management du système d'information (IAMSI)** → intégration et pilotage du SI.

### Logiciels à connaître

- WMS → entrepôt / logistique
- CRM → clients / marketing
- GPAO → production
- GMAO → maintenance
- ERP → centralisation des fonctions de l'entreprise
- ATS → recrutement
- LMS → formation
