## Fiche express : les 25 notions à connaître absolument

| Notion | En une phrase |
| --- | --- |
| **Rareté** | Les ressources sont finies alors que les besoins sont illimités : c'est le problème économique de base. |
| **Arbitrage** | Choisir une option, c'est renoncer à une autre (ex : quelle énergie utiliser). |
| **Agents économiques** | Ménages, entreprises, administrations publiques, institutions financières, ISBLSM, reste du monde. |
| **Utilité / valeur** | Le consommateur maximise sa satisfaction ; valeur = utilité + rareté. |
| **Profit** | Chiffre d'affaires − coûts (objectif du producteur). |
| **Spécialisation** | Chacun produit ce qu'il fait le mieux, puis on échange : bénéfices mutuels. |
| **Flux réels / monétaires** | Un bien ou service circule dans un sens, l'argent dans l'autre. |
| **Facteurs primaires** | Travail et capital. |
| **Facteurs secondaires** | Information et ressources naturelles. |
| **Intensité capitalistique** | Choix de produire avec plus de machines (capital) ou plus de personnes (travail). |
| **PIB** | Mesure de la production annuelle d'un pays (France 2024 : 2917 Md€). |
| **Valeur ajoutée** | Valeur créée par l'entreprise. |
| **Croissance** | Évolution quantitative du PIB, mesurée chaque année. |
| **Développement** | Amélioration qualitative et durable des conditions de vie, mesurée par l'IDH. |
| **IDH** | Espérance de vie + niveau d'instruction + revenu national brut. |
| **Capacité / besoin de financement** | Les ménages épargnent (capacité), les entreprises empruntent (besoin). |
| **Autofinancement** | Financement interne, « gratuit ». Sinon : marché ou crédit bancaire. |
| **Structures de marché** | Monopole, oligopole, concurrence ; les barrières à l'entrée protègent les acteurs en place. |
| **État-gendarme / État-providence** | Intervention minimale vs protection de l'intérêt général. |
| **Fonctions de Musgrave** | Allocation, redistribution, régulation. |
| **Défaillances de marché** | Asymétrie d'information, concurrence imparfaite, externalités négatives. |
| **Bien public** | Pur : non-rivalité + non-exclusion. Impur : rivalité mais non-exclusion. |
| **Politique conjoncturelle / structurelle** | Court terme (relance ou rigueur) vs réformes en profondeur. |
| **Règles européennes** | Déficit public ≤ 3 % du PIB, dette ≤ 60 % du PIB. |
| **FMN / IDE** | Multinationales qui optimisent leur chaîne de valeur / investissements directs étrangers. |
| **Développement durable** | Répondre aux besoins du présent sans compromettre ceux des générations futures. |

## Chiffres du cours à retenir

- **PIB France 2024** : 2917 milliards d'euros ; croissance 2023-2024 : 1,2 %
- **TVA** : 27 % des recettes de l'État en 2024 (chiffre donné dans le support de cours)
- **Prélèvements obligatoires** : 45,2 % (2022) ; dernier budget équilibré : **1974**
- **SMIC** : 1801,80 € brut / 1426,30 € net (depuis janvier 2025)
- **Sécurité sociale** créée en **1945**
- **Écart de niveau de vie** 10 % les plus riches vs 10 % les plus pauvres : **1/18 avant redistribution → 1/3 après**
- **Coût du travail** : 24 €/h en Espagne vs 42 €/h en France
- **Critères européens** : déficit 3 % max, dette 60 % du PIB
